# Registros de decisão arquitetural

Este diretório receberá ADRs quando o projeto precisar escolher entre alternativas
com impacto duradouro.

Use nomes no formato `NNNN-titulo-curto.md` e registre:

- contexto e problema;
- opções consideradas;
- decisão;
- consequências positivas e negativas;
- condições que podem justificar revisar a decisão.

O baseline não possui ADRs: suas escolhas simples estão descritas diretamente em
`docs/architecture.md`.
